## 2. 相关工作排除了哪些“伪创新”

| 已有工作 | 已经解决或讨论的内容 | 对本研究的约束 |
|---|---|---|
| LeWI（空闲时借出资源），ICPP 2009 [1] | 同节点内，用内层线程资源缓解外层进程不均衡 | “轻进程借核给重进程”不能独立称新算法 |
| Hints to Improve Automatic Load Balancing with LeWI（改善自动均衡的建议），JPDC 2014 [2] | 并行区/任务粒度和进程布局影响资源回收及均衡效果 | 仅增加安全点、细分并行区或增加阶段提示，也不足以证明创新 |
| MPI+X: task-based parallelization and dynamic load balance of finite element assembly（有限元装配的任务并行与动态均衡），2018预印本、2019期刊 [3] | 已把任务并行与DLB用于难以事先估计代价的有限元装配，验证至约16k核 | “网格相关计算＋动态借核”并非空白；装配与本项目体生成不同 |
| AC-DS（自适应分层调度），2014预印本 [4] | 反馈驱动的资源需求与分配，研究整体完工时间 | 在线反馈和最小化最慢完成时间本身都不是新目标 |
| heSRPT（高效率最短剩余处理时间调度），2020 [5] | 在并行收益递减下联合考虑任务大小和资源分配，目标为平均减速比/流时间 | 不能直接把平均任务完成最优等同于同步程序的最慢进程完成最优 |

本轮检索足以排除上述宽泛创新说法，不能证明下述组合方案尚无人研究。论文贡献应由明确算法差异、正确性条件与对照收益共同支撑。

## 3. 候选研究：修复阶段约束下的在线资源分配

研究对象保持同一份分区和同一套网格修复操作，只改变同节点各进程占用的工作核数。目标是缩短进入下一同步点前的尾部计算，而不是把单元数量分得更均匀。借出的核运行借入进程自己的线程，访问其原有内存；不把另一进程的网格指针当作共享地址，不迁移四面体，不新增分区面。

值得检验的具体差异是：结合修复的“并行候选评价—有序拓扑修改”交替结构，在工作量已经显式可见的阶段做短期分配，避免继续预测整块几何的最终体生成成本。候选数、邻域规模只能描述当前评价任务，不能从非法单元数直接推断剩余修复轮数。

### 3.1 分配与回收边界

每个进程始终保留一个主线程核，承担串行提交、资源回收以及消息通信进展。其他工作核只能有一个使用者。租约覆盖一个完整的安全执行区间，运行中的任务不可被抢占；持有者结束该区间并确认工作线程退出后，才能把核交还资源池。

首选边界是并行评价结束、串行拓扑提交开始的位置；次选较粗的完整修复算子边界。两者的响应延迟不同，需要计入代价。当前 `RemoveIllegalElements` 外层任务管理器贯穿整个调用，嵌套创建新管理器不会自动改变活动线程数。因此仅增加一个线程数变量不是实现；必须调整任务管理器生命周期并保证内存访问结束后再还核。

串行提交阶段可释放额外核，但不能将主线程核误判为空闲。进入阻塞通信也先保留一个进展核。不得以新增全局屏障来协调借核，否则可能重新制造正在解决的同步等待。若节点内没有可借核，立即沿用已有资源，不等待别人提供资源。

### 3.2 在线模型与决策

对进程 i 的当前已形成候选集合，记录剩余候选工作量 q_i；分别积累标记、拆分候选评价、交换候选评价的实际耗时。以本次运行中的完成任务更新各阶段吞吐量 r_i(k)，k 为真正获得的核数。不同操作的样本分开，网格发生明显变化时降低旧样本权重；不读取旧实验进行离线拟合。

短期估计可写为：

    当前阶段剩余时间 t_i(k) = q_i / r_i(k) + 串行尾部估计

这里的 r_i(k) 不假设随 k 线性增长。尚未观测的核数配置不能冒充可靠预测；冷启动采用固定分配或普通空闲借核，在线探测必须有预算并计入核心时间。模型误差、线程创建/销毁、资源申请、亲和性调整均进入收益核算。

在一个节点含 R 个进程、C 个已分配核的条件下，对可立即调整的租约考虑整数分配：

    最小化 max_i [t_i(k_i) + 重配置代价_i]
    约束 sum_i k_i <= C；k_i >= 1；活动租约保持不变。

小规模节点可用离散动态规划求解给定预测表的分配：D(j,c) 为前 j 个可调进程使用 c 个核时的最小预测最大时间，枚举第 j 个进程的核数并取最小值；复杂度 O(R C²)。固定活动租约与串行主线程的核数先从预算扣除。此动态规划是标准求解手段，不作为创新点；最优性只相对于这次给定预测表，不代表真实全流程最优。

仅当“当前分配的时间估计下界”大于“新分配的时间估计上界＋切换代价”时切换，否则保持原分配。上下界首先是在线残差形成的经验误差带，不应未经校准称为统计置信区间。它只能降低误判概率，不能保证从不退化。

这是滚动的阶段目标，尚不是精确预测到最终同步点的目标。若阶段变快而核心不变，说明短期目标未命中关键尾部，方法不成立，不能继续仅以预测均衡改善辩护。

### 3.3 实现必须维持的条件

1. 每个核同时至多服务一个进程；借出进程不得继续在该核运行旧工作线程。只使用作业已获得的核集合，不越过调度器的控制组或亲和性权限。
2. 候选评价读到的拓扑在该轮保持有效；网格插入、删除和提交顺序沿用已有规则。线程数变化不应改变候选排序的确定性处理。
3. 资源元数据只在节点内共享，不共享原始网格指针。原始进程数量、分区归属、稀疏面依赖保持不变。
4. 主线程不等待额外资源，活动租约只在安全边界回收；节点初始化、管理开销进入粗网格后的核心时间。
5. 集群如果不允许同作业内跨进程核亲和性调整，应明确报告“不支持”，不能退化为多个进程争用同一批核后声称完成资源协作。

## 4. 实验必须回答的问题

当前一节点一进程的数据无法验证节点内借核，因此下一原型必须使用同节点多个进程。但改变布局也会改变竞争和工作量分布，所有对照须在新布局下重新同条件运行。

| 项目 | 原型接通后的首轮计划；尚未设为运行默认 |
|---|---|
| 节点数 | 1、4、16 |
| 每节点进程数 | 4 |
| 总进程数 | 4、16、64 |
| 每节点总核数 | 固定16核，初始每进程4核 |
| 核预算 | 每进程保留1核；其他3进程只用主核时，单个忙进程最多13核 |
| 网格参数 | 固定原输入及 LEVELS=1、REFINES=1；记录实际单元数 |
| 主对照 | 固定4核的并行修复；普通空闲借核；阶段代价指导的分配 |
| 通信 | 三组均使用已验证稀疏通信 |
| 计时 | 自然核心为主，拆分等待用于解释；1次预热、5次正式 |

若普通借核是自实现，只能标记为“LeWI思想的简化对照”，不能标成官方DLB结果。应尽可能以官方DLB及合适的Netgen适配补充强对照；Netgen使用自己的任务运行时，不能假设仅设置OpenMP环境变量即可完成接入。

新增方案与普通借核共用相同的安全边界、亲和性管理和计时，避免把实现差异当成调度算法收益。必要消融只保留“取消代价指导”“取消阶段提前释放”；不重新加入已失败的邻域限制、旧分区模型和离线核验。

首要判据：相同资源和工作量下，自然核心时间稳定下降。辅助证据为最慢进程计算时间、到达时间分散程度、拆分等待以及借核实际使用的核秒。资源管理耗时、归还延迟、不同线程数下的实际吞吐量应输出紧凑汇总；不新增大量逐候选日志。

必须区分三种结果：

- 比固定修复快、但不比普通借核快：证明通用资源协作有用，尚不支持新调度贡献。
- 比普通借核稳定更快，同时核心和尾部时间下降、网格质量不恶化：支持候选算法的增量价值；仍需更多几何/规模验证。
- 仅单个阶段、预测值或等待变好，核心不改善：不判成功。若收益被回收/创建成本吃掉，说明粒度或运行时机制不适合，应依据实测停止该路径。

节点内方案不能消除整个节点都很慢、其他节点空闲的情况。也不能把串行拓扑提交自动并行化；若剩余瓶颈属于这些情形，应切换研究对象，不能无限增加本方案参数。
