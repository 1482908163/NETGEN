# 2026-11-17：保序映射验证与调用边界资源调度原型

## 定位与状态

新分支：`agent/ordered-mapping-balance`。从完整版本 `5e4dd6115f5b825cffc5b52742d1b074e6aa58ad` 派生。
这次是负载均衡机制的首版代码，未在助手环境编译、测试、语法检查或运行性能实验；没有新增收益结论。

主比较基准继续采用固定四核工程版 `node_engineered/baseline`（`fixed_recovery_v1`）。
完整版本 `node_rules_recovery_refine_hash/sparse` 作为冻结研究起点。
前者用于组合总收益，后者用于本轮新增机制的增量；组合总收益不能全部归因于负载均衡。
本轮不继续叠加细化缓存、恢复准备等工程微优化，不重跑已停止的固定旋转链和前缀切片方案。

## 第一项：保序供给、并行验证、原序归并

原动态整规则队列保留。完成自己整规则工作的线程，协助尚未完成规则的完整映射验证：

1. 原规则所有者继续按原顺序枚举映射、计算新点位移、执行自由区变换。
2. 只有出现帮助线程且预算允许时，复制完整映射输入和变换后的自由区状态；不在帮助线程重新执行搜索前缀。
3. 帮助线程恢复自己的规则副本，执行原自由区、几何、方向与质量检查，生成私有候选。
4. 原所有者按映射顺序归并诊断、可用计数、最小质量、胜者和输出；结果不按完成先后归并。
5. 规则结束、串行回退和异常退出前排空已发布任务，保证被捕获的局部数组仍然存活。

保留旧自由区平面矩阵的历史状态，包括退化分支未覆盖的行；本轮不改变几何算法。
高容错诊断也进入原序归并，相邻无候选观察的诊断标记可合并，避免失败枚举无限积累标记。
任务由现有规则线程组执行，没有嵌套线程组。若底层任务尚未全部启动，已完成回调直接返回，避免占住线程等待未派发回调。

每个线程默认最多前瞻 2 个队列事件；全调用预算为线程数乘窗口的候选槽位，估算候选载荷合计上限 64 MiB（兆二进制字节）。
这是估算载荷预算，不是进程常驻内存上限；帮助线程的持久规则副本和分配器开销不在该统计内。
原枚举和状态生成仍是串行限制；复制、队列、归并可能超过并行收益，必须实测。

## 第二项的已实现范围

本版只实现每个请求者在**完整规则调用之间**选择核数、领取批量与前瞻窗口：

- 按容错等级、局部点数及面数的对数区间保存观测，至少 3 次同核数样本才考虑模型决策。
- 模型使用当前核数调用耗时的观测最小值、状态工作代理、总工作量、最大单次验证耗时、队列成本与线程组重建成本。
- 枚举当前核数至现有可用容量，批量为 1/2/4，窗口为批量的两倍且不超过 8。
- 预测成本为 `1.25 * max(状态代理, 总工作量/核数, 最大验证耗时*批量) + 队列成本/批量 + 重建代价`；增核时重建代价取最近一次重建耗时的两倍。
- 只有预测值低于当前核数的观测最小耗时才采用；25% 是明确的模型裕量，不是概率置信界或收益保证。
- 先在节点共享锁下预留准确数量的已完成进程空闲核，再停止线程组、归还旧租约并取得新租约，重建线程组。
- 本版只增长，不缩核；四核保底、其他进程的通信锚点以及原物理核所有权检查保留。抢占预留失败时保留当前资源。
- 样本不足、没有帮助工作或没有预测收益时，保持当前分配，不插入探索运行。

**尚未实现：** 调用内部可恢复执行段、节点级所有请求者联合分配、全局剩余工作预测以及缩核回收。
因此路线名中的联合仅表示调用边界的核数与任务批量选择，不代表完整节点级联合算法已完成。

## 对照路线

| 路线 | 作用 |
| --- | --- |
| `node_engineered/baseline` | 原通信、原规则搜索、固定四核修复与恢复工程基准 |
| `node_rules_recovery_refine_hash/sparse` | 冻结完整版本，本轮增量分母 |
| `node_mapping_capacity/sparse` | 仅允许规则调用之间使用已完成进程的空闲核，不启用映射任务 |
| `node_mapping_tasks/sparse` | 第一项；规则阶段保持原四核上限 |
| `node_mapping_joint/sparse` | 第一项加第二项调用边界原型 |

第三条用于判断收益是否仅来自解除规则阶段四核上限。四、五条比较调度增量；五与第三条比较是否超出简单扩容。
旧默认实验矩阵不变；新预设必须显式选择。

## 验证与统计

预热沿用现有逐调用串行重放，另从相同自由区初态重放并比较最终变换点与全部平面矩阵位模式。
既有输出、规则胜者、质量、诊断、工作量计数以及网格审计继续执行。正式计时不重放。
预热失败则跳过该路线正式运行并保留失败证据；未实际派发映射任务或未实际增核时记录为未覆盖，不宣称机制有效。

新增 `ordered_mapping_` 前缀统计包含：调用、任务、快照成本、并行/原位验证成本、归并等待、容量拒绝、估算峰值载荷、状态工作代理、最大状态链代理、重放与不一致、决策次数、实际扩容、预测收益、冷启动、队列领取成本、重建成本和线程/批量峰值。
归并等待包括期间协助执行的工作，不能当作纯空转；状态代理由线程总时间扣除验证和显式等待得到，不等于精确串行关键路径。
分项互有包含，不能相加还原核心时间；预测收益不是实测降时。保留全进程记录，以同一关键进程追踪成本。

分析器区分固定核与已完成进程供核两种资源契约，不把合法增核误判成预算违规。
本轮五路线不强制补跑同等索引工程基准；这是保持用户指定的主比较基准，并以冻结完整版本隔离新增机制。历史细化实验仍保留其原配套对照要求。
