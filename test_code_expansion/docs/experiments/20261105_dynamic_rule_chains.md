# 动态整规则链与批内缓冲复用：待集群验证

上一批集群证据：较大成功前沿 1,207 单元中，固定旋转链比原动态路线慢 18.97%；单纯换成批量动态队列仍慢 14.73%。减少汇合有收益，但准备次数未减少，固定归属和批量布局有额外代价。此次针对这些问题改变任务与数据生命周期，不重跑旧方案的完整矩阵。

**当前仅完成实现及源码阅读复核。没有在助手环境编译、执行测试或提交集群作业，不能声称等价性或性能已经通过。**

## 沿用原来两条命令

更新代码后，在原有超算编译环境的仓库根目录执行：

```bash
bash test_code_expansion/build_project.sh
bash test_code_expansion/strong_scaling/run_experiments.sh
```

第一条只编译，成功后再执行第二条。当前默认配置是 `rotation_chain_dynamic`，提交一个节点、一个进程、四核的成本消融作业。实验使用 `build/rotation_chain_dynamic_v3`，不覆盖生产安装或旧版实验构建。

原有生产构建和历史实验仍可通过显式 `EXPERIMENT_PRESET`（实验配置）选择；默认不会重复已完成的跨节点矩阵。此前新增的用户编译包装脚本已删除，Python 构建模块仅作为原入口调用的内部实现。

## 新路线与可区分的变化

| 路线 | 规则链分配 | 输入工作缓冲 | 作用 |
|---|---|---|---|
| 0 | 原逐旋转动态队列 | 原实现 | 总体基准 |
| 4 | 动态领取一整条规则旋转链 | 每条规则、每次旋转重新分配并复制 | 动态分配候选 |
| 5 | 同路线 4 | 每个工作任务、每个旋转保留一个缓冲，复用原始几何前缀 | 缓冲复用候选 |
| 6 | 固定归属整条规则链 | 同路线 4 | 同布局的分配对照 |

6→4 区分动态/固定分配；4→5 区分缓冲复用；0→4/5 衡量包含准备组织变化的净收益。路线 6 不是旧路线 1，不能把它们当成同一实现直接拼接结果。

三个新路线都在同一前沿批次内为每个旋转建立一次只读规则准备，批次结束即释放，不跨前沿缓存。没有共享准备时，单规则粒度会重复执行昂贵准备；因此三个新路线统一采用这一组织，保证分配消融使用相同布局。它延续了此前共享预处理尝试，但复用范围由单次工作队调用变为多个整规则链；不因复用次数增加就预先宣称有效。

完整前沿的新路线延后填充输出几何，避免先复制默认输出又被胜出结果覆盖。此项对 4/5/6 一致，属于 0→新路线的组合变化。

## 顺序、状态与缓冲边界

- 一个规则被领取后，其所有旋转始终由同一个工作任务按原顺序完成，之后才领取下一规则；不改变前沿推进顺序。
- 规则几何历史和诊断槽只由该规则链的拥有者修改。不同规则的结果按原质量与规则编号平局规则归并；工作计数和逐旋转最小值均合并。
- 复用路线每次调用前清空输出、计数、局部最小值等状态。原始点/面的前缀保持，追加部分截断；候选胜出几何另存，避免后续复用覆盖结果。
- 差分阶段对每次复用检查原始点坐标及面连接未变化，并核对复制次数、链覆盖、派发次数及完整结果/工作指纹。发现差异立即停止，不继续性能计时。
- 缓冲仅在一个前沿批次内复用，容量随该批次输入增长；不建立长期全网格缓存。规则搜索内部的临时数组仍按原实现构造，此次并未消除全部准备成本。

分项报告增加共享准备墙钟、工作缓冲重置/复制累计、整链领取累计，以及共享准备数、规则链数、规则×旋转访问数和输入前缀复制数。工作任务累计区间不能与主线程墙钟相加。计时探针只在分项构建启用，正式性能使用普通构建。

## 验证安排与地址检查受阻

默认计划 788 个唯一实验运行：普通差分 132、独立未定义行为差分 72、分项差分 72、地址检查差分 72、普通计时 416（含预热）、分项采样 24。另有 16 项驱动检查，由同一集群作业执行。旧路线 1/2/3 不进入新性能矩阵。

地址检查首先运行同一检查矩阵中的首个串行样例。若明确出现 `ReserveShadowMemoryRange failed`（影子地址空间预留失败），记录地址空间、数据段、栈的软/硬限制，不修改这些限制；随后仍完成普通、独立未定义行为和分项阶段。真正的越界、未定义行为或其他进程错误不会被降级为环境受阻。

受阻时 `address_check.status=blocked`（地址检查受阻），`complete=false`（未全部完成），程序返回 3；若性能完成则另记 `performance_complete=true`。不能把这一状态写成全部通过。诊断用于定位环境问题，不声称已经解决底层地址空间限制。

同版本、同参数续跑可复用成功样本，只重新尝试影子空间启动失败项；原失败记录保留，新记录标记尝试次数。独立未定义行为检查不替代地址检查；二者均仅对实验翻译单元插桩，其他内核对象未全面插桩。
