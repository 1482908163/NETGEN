# 恢复阶段拓扑重建去重与平滑后复用

基于 `20dc740` 核实的上一批结果，128 节点优化后的关键计算进程转到 463：
该进程恢复约 7.83 秒，其中拓扑准备约 3.33 秒。64 节点关键进程的恢复约 10.50 秒。
本版继续降低这条关键路径的实际工作量；集群核心时间收益待同批实验确认。

## 改动与等价性依据

原恢复序列 `mcmstmcmstmcmstmcm` 共 **18 步**，顺序保持不变。
每步原来执行：查找开面、重建表面信息、确定开腔周围可修改单元、再次重建表面信息。

1. **去掉同一步内第一次表面重建。** 中间的 `FreeOpenElementsEnvironment`（开腔邻域标记）
   只读取连接和开面，写入单元固定标记及点类型；三维 `CalcSurfacesOfNode`（表面信息重建）
   会重新设置所有点类型，并从当前表面、线段、锁定点等重建查询表。
   第一次重建的结果没有保留到后续优化操作。二维不满足相同的全点重置条件，保留原路径。
2. **仅在紧邻平滑操作后复用准备结果。** 当前 `ImproveMesh`（体网格平滑）不会增加、删除或改连单元，
   不修改开面与单元固定标记。不过其边界表构造会临时固定开面点，点目标函数还可能重新赋值点对象。
   因此在平滑前保存点类型，在下一步准备时只恢复这些类型并清空边界边缓存；保留平滑后的坐标、层号和奇异性属性。
   这与原准备阶段最终状态一致。任何合并、换边操作之后均重新准备，不跨拓扑修改复用。

每轮 18 步中有 7 步紧接在平滑之后。因此，三维正式路径中：

| 恢复循环内操作 | 原路径 | 候选路径 |
| --- | ---: | ---: |
| 查找开面 | 18 | 11 |
| 开腔邻域标记 | 18 | 11 |
| 表面信息重建 | 36 | 11 |
| 平滑前保存、下一步恢复点类型 | 0 | 各 7 |

末尾的问题单元移除和开面检查不变。原有安全检查点、线程团队重建、借核归还、
平滑着色顺序以及合并/换边提交顺序均保留。额外存储为当前网格每点一个点类型。
这是基于当前平滑实现的明确失效边界；以后若平滑改变连接或单元固定标记，必须撤销或更新复用条件。

## 对照、重放与诊断

- 对照：`node_rules_recovery_front`（上一轮前沿优化版）。
- 候选：`node_rules_recovery_topology`（叠加本轮两项拓扑优化）。
- 两者沿用前沿优化、恢复并行和相同借核策略。新贡献项为 `recovery_topology`（恢复拓扑增量）。
- 候选预热模式 2：每步准备后完整重放原准备序列，逐项比较点类型、所有单元固定标记，
  以及开面的类型、域号和顶点顺序。有差异立即失败；不重放平滑/合并/换边操作。
- 正式候选模式 1，原准备模式 0；正式轮禁止重放。预热仍执行前沿、规则重放和完整质量审计。
- `ordered_topology_reuse_v1`（有序拓扑复用版本）记录 5 项计数：准备调用、优化调用、验证、差异、
  相对原路径省去的表面重建。每轮候选应为 `18 / 18 / (预热18，正式0) / 0 / 25`。
  “省去”是候选算法路径的逻辑计数，预热的额外参考调用不计入此数，也不作为正式性能。
- 分析脚本逐进程核对上述计数与恢复轮数，拒绝零覆盖、缺失、非整数、非有限值和不完整重放。
  新计数保留在精简缓存和关键进程报告中；旧接口数组长度不变。

两项优化合并对照，不从一次实验分别宣称两项各自的核心时间贡献。

## 本地验证

完整验证记录见 `20261028_recovery_topology_validation.json`。

- 独立 Release（发布）内核构建通过；本地没有 OCC/METIS 依赖，未完成集群主程序的完整构建。
- 14 组准备阶段差分，覆盖二维回退、三维、原/优化/重放模式、锁定点、线段、无引用点、
  删除单元以及无表面描述的网格，核对点分类、固定标记、开面和边查询。
- 150 组完整开腔恢复差分：原序列对照，覆盖原/优化/重放、1/2/4 线程、线程重建和调用方已有团队。
  检查坐标、点类型、层号、奇异性、单元顺序、固定/删除标记、表面及开面；异常租约归还检查保留。
- 原有前沿差分、完整生成源码对照、18 组规则检查、四进程 MPI（消息传递接口）、公共接口边界保护通过。
- 41 项分析/编排测试，以及运行器的失败续跑、预热过滤、压缩续跑和清理检查通过。

对改动的 `meshfunc.cpp` 及恢复测试执行 AddressSanitizer（地址检查）和
UndefinedBehaviorSanitizer（未定义行为检查），通过。其余内核对象未全部插桩，泄漏检查关闭。

同进程、单线程、交替执行顺序，丢弃一次预热后取 5 次中位数：

| 合成恢复样例 | 原恢复总时间 | 新恢复总时间 | 原拓扑准备 | 新拓扑准备 |
| --- | ---: | ---: | ---: | ---: |
| 6×6×6 网格开腔 | 51.14 毫秒 | 47.69 毫秒 | 7.93 毫秒 | 4.83 毫秒 |
| 10×10×10 网格开腔 | 208.46 毫秒 | 191.31 毫秒 | 30.73 毫秒 | 18.34 毫秒 |

两例恢复总时间分别下降约 6.76% / 8.23%。只去掉第一次表面重建的独立准备样例收益较小：
10,367 单元为 2.866→2.844 毫秒，82,943 单元为 23.823→22.498 毫秒。
这支持同时减少平滑后的重复拓扑扫描，但合成网格结果只验证机制，不能代表超算核心时间收益。
