## 与旧方法的区别及等价性依据

原 `FreeOpenElementsEnvironment(2)`（两轮邻域距离传播）进行两遍原位松弛，再扫描一遍单元设置固定标记，最后修改点类型。原位扫描可能在同一遍传播很远，不能直接等同于两遍同步传播的完整距离数组。
但距离是函数内临时数据，最终只使用两个阈值：单元最小距离是否大于 2；点距离是否大于 3。本轮保留这两个分类集合，不要求保留没有读者的较远距离。

把每个有效、未删除的体单元视为连接其全部点的集合，开面种子距离为 1：

1. 每次原距离更新都沿真实单元加 1，不会把远处点错误标进近区。
2. 第一遍完整扫描后，与种子共单元的全部点必已获得距离不大于 2，与扫描顺序无关。
3. 第二遍后，从这些近区点再经过一个单元可达的点必已获得距离不大于 3。
4. 因此距离不大于 2／3 的集合，恰好对应一层／两层可达集合；更远处的原位传播差异不会改变最终判定。

此推导仅用于固定两层调用。通用层数函数保持原样，二维恢复保留原路径。有效性与删除判据不变，支持原函数遍历的单元点集合，不新增邻接表，也不跨拓扑修改缓存。

## 两遍扫描

每点一字节：0 表示范围外，1 是开面种子，2 是一层点，3 是第二层点。

- 第一遍只读取状态 1，触及种子的单元将状态 0 写为 2，不能用新状态 2 继续传播。
- 第二遍只读取状态 1／2，同时设置单元固定标记，将其余状态 0 写为 3；新状态 3 不成为传播来源。
- 最后将状态 0 的点设为固定类型，其余点保留输入类型。

体单元完整扫描从三遍减为两遍，整型距离数组改为字节分类数组，仍为串行线性扫描。没有新增建图、任务派发、原子操作。这是源代码结构与语义推导，不是性能实测，不提前宣称创新或加速。
