# 有序旋转链：统一消融测试与结果

本轮在 c77be8ee 原型上拆分固定分工、旋转间汇合和批量输入组织的影响。生产内核、默认实验入口未修改。工作区续接曾丢失未提交输出，本报告仅使用此次重新生成并归档的完整记录，不混用丢失运行的统计。

实际运行：2026-11-05 16:10:34 至 16:22:01（北京时间）；文件前缀沿用 20261030 研究系列。

## 一次运行或一次作业提交

仓库根目录本地运行：

```bash
bash test_code_expansion/tests/run_rotation_chain_suite.sh
```

超算登录节点一次提交，默认 mt_module 分区、1 节点、1 进程、4 核：

```bash
ROTATION_PARTITION=mt_module bash test_code_expansion/tests/run_rotation_chain_suite.sh --submit
```

需要预先配置可用的 C++ 编译器、CMake、Python 3 和 zlib 开发环境。脚本在独立目录构建内核，随后依次执行驱动检查、普通构建差分与计时、分项测量、地址及未定义行为检查；失败立即退出。脚本不调用 Git。本轮没有实际提交超算作业，调度包装通过模拟命令验证。

可用 `--build-dir`、`--output-dir`、`--cmake`、`--ninja` 指定路径。默认每组 12 个正式计时块；`--blocks` 至少为 4 且须是 4 的倍数。已有结果禁止覆盖；`--resume` 仅在清单中的源码、参数及实验可执行文件摘要匹配时复用样本，不能保证所有共享库依赖均未变化。

## 消融路线

| 路线 | 规则分工 | 旋转间汇合 | 输入组织 |
|---|---|---|---|
| −1 | 串行基准 | 原顺序 | 原路径 |
| 0 | 原动态队列 | 每次旋转 | 原路径 |
| 1 | 固定规则归属 | 整条旋转链结束 | 预先分配批量缓冲 |
| 2 | 固定规则归属 | 每次旋转 | 同路线 1 |
| 3 | 共享动态队列 | 每次旋转 | 同路线 1 |

2→1 比较同样固定分工下合并汇合的效果；3→2 同时反映固定归属与队列结构的变化，不能全归因于负载不均。0→3 同时改变批量布局、包装及无输出流处理，不是纯复制成本消融。本轮将队列构造移到派发之外，路线 1 也属于新一轮测量，不能直接拼接旧原型耗时。每条规则内部保持原有旋转顺序、历史状态、诊断、最小值及平局选择。

## 结论与边界

140／1,197 单元完整前沿上，路线 1 相对路线 0 的配对中位降幅为 −5.95%／−1.56%，仅 4/12、5/12 胜出，未通过整体收益门槛。在相同固定分工和缓冲布局下，2→1 为 +4.83%／+9.20%（7/12、9/12 胜出），支持合并汇合能减少部分开销；3→2 为 −11.17%／−9.29%，显示固定归属及其队列结构在当前输入上存在代价。0→3 为 −0.96%／−0.83%，均仅 6/12 胜出，也不足以认定批量布局改善整体性能。不能把全部差值直接解释为纯调度开销或纯负载不均。

不同构建的完整前沿指纹一致性如下；“否”表示不同编译/插桩构建产生了不同结果，不能声称跨构建等价：

| 样例 | 分项构建与普通构建 | 内存检查构建与普通构建 |
|---|---|---|
| 0 | 是 | 是 |
| 1 | 是 | 是 |
| 2 | 是 | 否 |
| 3 | 是 | 是 |
| 4 | 是 | 否 |

内存检查仅对实验翻译单元启用 AddressSanitizer（地址检查）和 UndefinedBehaviorSanitizer（未定义行为检查），其余内核对象保持普通构建；泄漏检测关闭，未运行线程竞争检查。通过表示已测样例没有报告这些错误，不证明所有输入、整个内核或所有竞争情况均安全。

这些是合成前沿与局部样例，不能替代真实 CAD（计算机辅助设计）模型、MPI（消息传递接口）或跨节点扩展测试。本轮不提升候选为生产默认，不重复已经完成的 64/128/256 节点覆盖修正矩阵。后续可研究动态分配整条规则旋转链并限制重复准备开销，但当前并未实现。
