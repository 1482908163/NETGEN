新搜索排序相对旧对照三轮均慢，没有进入默认性能主线的依据。

这些阶段存在包含关系，不能相加。核心降时约 17.12 秒，与关键进程生成内部恢复的约 17.12 秒下降相符，
支持恢复并行确实缩短关键路径。剩余生成、前沿处理和体细化仍有明显成本。
前一批面 2 同批降时为 13.56%，本批面 4 为 23.43%；两种规模均有有效对照，但都在 64 节点，
**还不能由此认定跨节点数的扩展性已经解决**。
