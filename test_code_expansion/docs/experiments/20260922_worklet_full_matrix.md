## 指纹不稳定的明确代码问题

Refine 和 Refineforvol 构造子面时未赋值 outw，task_fingerprint 和回传序列化却读取它。
不仅跨策略指纹不同，静态重复本身也变化。最终体网格指纹一致不能消除未初始化读取问题。
本次初始化临时面，并令全部四个子面继承父面 outw；顶点顺序、几何计算和指纹检查规则保持不变。
这是已确认的代码缺陷，是否解释全部指纹差异仍需真实运行验证。

新增回归直接编译生产 Refine、重心坐标函数，使用小型网格接口替身，检查两级细化的朝向继承、描述符和面积。
在旧实现上朝向断言失败，修复后通过。不是 MPI/OCC 集成测试。
