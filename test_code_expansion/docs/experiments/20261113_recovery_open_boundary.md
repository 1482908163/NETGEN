## 与旧方法的区别

旧拓扑版取消第一次表面重建，并复用平滑前后的拓扑；它仍在每次实际开面查找末尾调用边界边构建及点类型标记。
本轮保留全部开面查找，只省略这段随后无读者使用、又必被覆盖的后处理。不是再次声称旧拓扑复用是新方法，也不是缓存拓扑改变前的开面。

原三维准备顺序为：开面查找 → 邻域标记 → 表面分类重建。开面查找末尾 `BuildBoundaryEdges`（构建边界边表）及后续循环仅写边界边缓存和点类型；`FreeOpenElementsEnvironment`（邻域标记）只读开面与单元连接，不读该缓存或旧点类型；最后 `CalcSurfacesOfNode`（表面分类重建）清空边界边缓存并重设全部点类型。因此这段后处理没有保留到优化操作的有效状态。

实现保留原 `FindOpenElements(int)`（开面查找）的公开签名与完整行为。新专用入口只在三维恢复准备调用，共享同一个内部查找实现，在有序开面列表与日志生成后返回。原入口、问题单元移除、二维等仍保留完整后处理。无需新缓存、哈希表或坐标／连接复制，也不改变任务划分、面插入次序、单元固定标记、线程租约和优化操作顺序。

若原边界缓存已存在，原构建函数可能提前返回，但之后开面标记循环仍会运行。本轮 `boundary_skipped`（省略边界后处理次数）统计的是省略调用路径，**不等于真实避免的内存分配次数**。每轮 18 步中的 7 步沿用旧平滑复用，另外 11 步走新入口；原表面重建省略数仍为 25，不是 31。
