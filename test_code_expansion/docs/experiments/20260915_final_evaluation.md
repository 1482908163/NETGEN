# 2026-09-15：完成后借核收敛与收尾评价协议

## 决策依据

本轮依据 [mesh_algorithms_20260915-020713](../../strong_scaling_results/mesh_algorithms_20260915-020713)；代码版本 `472c6418cf597a47a20be7f7bb4675b40afa47d9`，结果上传版本 `fa81b1e2330e07e4ca29e81a1aff18f418befa7f`。

完成后借核相对固定资源下降 5.89%、7.06%、12.57%。最终优化借核相对完成后借核仅下降 0.55%、0.65%、0.28%，同编号重复胜出 5/5、3/5、2/5；单次提前借核在 64 进程反而慢 1.87%。降低提前借核频率减少了开销，但没有得到稳定的额外净收益。

因此冻结 `node_elastic` 为主线，停止增加未经数据支持的提前分配规则。保留旧策略及结果以便复现，不修改模型、不继续采样。上述运行的单元数和 illegal 标记一致，只能支持原有计数对照，不能追溯宣称这些网格通过了本次新增几何审计。

## 一次提交的矩阵

仍用 `build_project.sh` 构建和 `strong_scaling/run_experiments.sh` 提交。五个规模 P=4/16/64/128/256，每节点 4 进程、每进程预留 4 个物理核，节点数 1/4/16/32/64。输入及细化参数不变：`wholewall3solid.STEP`、L=2、R=1、种子 -1，一进程一个分区。

| 组 | 算法 | 内核策略 | 对照问题 |
|---|---|---|---|
| A | baseline | node_original | 相同 CPU 池中的原串行修复流程 |
| B | sparse | node_original | B/A：稀疏通信 |
| C | sparse | node_native | C/B：并行修复 |
| D | sparse | node_fixed | D/C：整段线程组及固定资源接口 |
| E | sparse | node_elastic | E/D：完成后借核；E/A：总收益 |

`node_original` 复用已有 `Ng_GenerateVolumeMeshRepair(..., schedule=0, ...)`，`node_native` 使用 schedule=2；两者均初始化同一 CPU 池和初始核集，不进入协作回调。D/C 同时改变线程组作用域与资源管理接口，不能据此单独量化每一种内部开销。

每组 natural/split 各预热 1 次、正式 5 次：每规模 60 次运行、50 次正式；全批 300/250。五规模分别提交，不设置串行依赖；同规模按重复轮换内核策略，A/B 在同一策略轮次内交替先后，不宣称五组完全随机化。逐轮胜出只用于观察波动，不代表统计显著性。

新增 `COMMUNICATION_ABLATION=1` 只对 node_original 子驱动补充 baseline。`QUALITY_WARMUP=1` 将审计合并到自然 repeat_0；这两个开关进入配置签名，避免断点续跑混入旧协议。显式历史复现可关闭这两个开关，报告注明未审计。

## 质量门槛与可检验范围

审计在每个进程完成体细化后、邻接幽灵单元插入前执行。全部本地拥有的线性四面体均参与；不对幽灵副本重复计数。新增检查不运行于正式测量。

1. 每个点坐标有限，每个单元索引有效且四顶点不同；每个四面体均非零体积。记录正/负有向体积；整体统一的负方向编号允许通过，混合方向需核查。
2. 按无向三顶点编号归并全部四面体面：最多两个体单元共享，同一共享面的两个外法向应相反。体边界必须有表面记录，声明表面必须属于体单元；表面三角形不能为零面积。合法双侧材料界面可能有重复表面，单列计数并与对照比较，不直接判作非流形。
3. 平均比形状质量为 `q = 12 (3V)^(2/3) / sum(edge_length^2)`，正四面体 q=1。用最长边归一化后计算行列式，记录最小值、总和及十个等宽区间；统计每个四面体的六个内部二面角和体积。区间为 [0,0.1)、…、[0.9,1]。
4. 记录表面和体单元的坐标指纹，忽略单元内部顶点排列及局部编号。用每进程 64 位 sum/xor 配对摘要；每个 64 位值分成两个 32 位指标，避免 JSON 双精度损失。指纹是概率摘要，不是几何同一性的数学证明。
5. sparse 自然预热实际运行原全收集参考，核对稀疏面闭包及共享依赖。只有参考函数成功返回才记录通过。baseline 直接使用原全收集。

分析器要求计数与已有邻接前 NP/NE/NSE 一致、正负数及直方图总数等于已检查单元数；所有体单元必须已检查，结构错误为零。每组保留逐进程审计 JSON，汇总时重读原始 profile，不信任陈旧 JSON。缺失审计、来源不一致或未成功结束均标为异常。

相邻贡献组及 A/E 使用相同二进制、内核库、输入、种子、参数和资源布局。比较点/面/体计数、重复表面/内部标记计数、每进程边界指纹及总体积（相对容差 1e-10）；最小/平均形状质量、最小二面角不得下降，最大二面角不得上升（浮点容差 1e-10 × max(1, |参考值|)）。每个质量分位区间阈值以下的低质量单元累计数不得增多。网格变化但指标有改善/退化权衡时，保守标为需核查，不自动放宽门槛。

形状质量为不退化对照，并未制定满足所有下游用途的绝对最小 q 阈值。即使通过，也只证明这些预热网格满足上述检查：没有检查任意非相邻体单元重叠、CAD 曲面距离、全局幽灵层或 Elmer 输出；正式轮只有原有运行完整性、单元数与 illegal 对照，不能把 25 次审计外推为全部 250 次正式轮的几何证明。

扫描需额外 O(NP+NE+NSE) 内存、面排序 O((4NE+NSE) log(4NE+NSE)) 时间；每个面记录通常 16 字节，主体约 64×NE 字节，另有表面、点及指纹缓存。审计耗时留在预热记录，正式中位数直接排除 repeat<=0，不估计或扣除审计时间。

## 报告与完成路径

每规模统一 `RESULT_SUMMARY.txt` 报告运行异常、自然时间、贡献消融和质量门槛。`ablation_summary.csv` 保存相邻四项及总收益；`mesh_quality_summary.csv` 保存五组审计结果；旧内核和阶段表继续用于归因。

质量或启动失败后继续执行剩余实验，质量失败不写 SUCCESS，诊断现场保留。性能比较仍保存，但有异常时作业返回失败，不能据此作出最终正确性结论。

本批完成后先定位质量/完整性异常，再对同规模各贡献的自然净收益、重复波动及 split 等待归因给出结论。P 变化会改变分区及生成单元总数；扩展图须同时列 NE 和计算不均衡，不能称作严格固定网格强扩展。若当前检查通过且收益在较大规模仍稳定，再安排独立批次复现和完整输出/CAD 专项检查，最后冻结实现及论文表图。若任一门槛失败，依据本批保留证据修复相应问题，不预先承诺本批即为最终完成。
