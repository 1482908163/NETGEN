## 成本与机制

1207 单元，三个分项样本各字段独立取中位：
- 工作区复用使工作区构造数为 5768 次，输入复制 17304 次；规则调用仍为 116802 次。计数核对符合设计，不能说调用数消失。
- 路线 4→7 的任务派发区间从 238.74 ms 降至 176.99 ms，但串行共享准备仍约 105.81 ms；路线 7 相对原内核净收益接近零。
- 路线 7→8 的共享准备墙钟从 105.81 ms 降至 41.83 ms，派发区间约 174.79 ms。正式无探针数据也改善，支持并行准备对这个完整前沿样例有效。
- 小局部输入上路线 8 反而比路线 7 慢，说明额外准备派发与汇合需要摊销。下一步减少两个阶段之间的全体汇合，而不是用同一数据选一个阈值后宣称普适有效。

累计工作时间、等待间隔与墙钟重叠，不直接相加。分项探针不能替代普通构建性能。
地址检查仍在算法前因影子虚拟地址预留失败退出，进程地址空间、数据段、栈软硬限制均无限；根因未确定，不算通过，也不当作已发现算法越界。无需重跑这批性能。
