## 已有方法与新边界

旧拓扑版已经完成两件事：取消每步第一次无保留效果的表面重建；在平滑之后恢复保存的点类型，复用开面与固定标记。这些不是本轮的新贡献。

新增 `node_rules_recovery_surface`（换边后表面复用）：`SwapImprove`／`SwapImprove2`（两种换边操作）结束时调用 `Compress`（压缩与重新编号），其中最后已运行 `CalcSurfacesOfNode`（表面分类及查询表重建）。本轮在换边返回后保存**重新编号之后的新点类型**，仅供紧接的下一次准备使用：

1. 下一步仍调用 `FindOpenElements`（开面查找），不用拓扑改变前的开面结果。
2. 仍调用 `FreeOpenElementsEnvironment`（开腔邻域标记），重新计算单元固定标记。
3. 恢复刚保存的点类型，清空边界边缓存，省去再次重建表面／线段查询表。
4. 快照只用一次；后续换边返回后重新捕获。线程租约检查点、操作顺序、提交顺序和点优化数学不变，平滑依赖图关闭。

依据：上述两个准备函数读取体连接、开面和边界，写入点类型、边界边缓存及单元固定标记，不修改表面单元、线段、锁定点、点单元或表面描述；表面／线段查询表仍对应刚完成压缩后的编号。恢复点类型不回滚坐标、层号或奇异因子。

**不在合并操作后使用本复用。** `CombineImprove`（合并操作）在压缩后还调用非法单元标记，它可重建边界边并改变开面点类型；不能把此时点类型误认为纯表面分类。二维保留原路径；不跨任意拓扑修改缓存，也不增加全局缓存。

每轮原序列仍为 `mcmstmcmstmcmstmcm`，共 18 步。其中三次两类换边各产生一次可复用结果，因此每轮新增 6 次复用。旧高容错版准备阶段每轮表面重建 11 次，新候选为 5 次；查找开面和邻域标记仍各 11 次。压缩内部的表面重建不变，不能把 11→5 称为整个恢复阶段全部表面重建次数。

## 测量与正确性

拓扑模式 0 为工程原路径，1／2 为旧拓扑正式／预热，3／4 为本候选正式／预热。

所有路线新增同一组准备分项计时：开面查找、邻域标记、表面重建、分类保存、分类恢复。压缩内部重建仍在换边阶段；这些分项不是整个网格过程所有同名函数的计时。新增复制及缓存清理计入恢复准备总时间和完整核心时间，不能当作免费。
