## 覆盖与失败

原计划 18 路线 × 3 规模 ×（1 预热＋3 正式）＝216 次。

| 节点 | 已完成预热 | 已完成正式 | 启动失败 | 未启动 |

| 64 | 18 | 49 | 5 | 0 |
| 128 | 18 | 54 | 0 | 0 |
| 256 | 17 | 51 | 1 | 3 |
| 合计 | 53 | 154 | 6 | 3 |

6 次失败均为退出码 1，失败摘要记录资源确认阶段的套接字超时，随后打印作业号无效提示；没有程序检查点或网格启动证据。
它们不是已证实的几何算法失败，也不能仅根据第二行断言作业永久过期：同一作业随后仍有成功运行。

- 64 节点：工程基准的稀疏通信路线第 2 轮；旧借核、旧固定核规则并行、高容错、共享准备各第 3 轮。
- 256 节点：在线搜索路线预热失败，后续 3 个正式轮被跳过。

保留失败路线为无效比较，不删除失败轮、不给缺一轮的高容错 64 节点路线发布百分比，也不把新作业补跑混入旧配对。
