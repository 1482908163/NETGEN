## 地址检查为何失败

失败键：`sanitize/local/45/0/1/-1`，即内存检查构建的首个串行基线。进程返回 -6，约 0.05 秒退出，无算法结果。
原始错误为：

```text
AddressSanitizer failed to allocate 0x1bfe00000000 (30777735643136) bytes
ReserveShadowMemoryRange failed ... Perhaps you're using ulimit -v
```

这是 AddressSanitizer（地址检查器）启动时无法预留影子虚拟地址空间，不是报告算法需要约 30.8 TB 实际内存，也不是已经定位的代码越界。
错误提示虚拟内存限制可能是原因，但此次没有记录进程地址空间软/硬限制，尚不能确定具体限制来源。
后续只需针对检查器启动记录地址空间限制和运行时信息，并补未完成检查；不应盲目取消调度限制，不能把失败改记为通过。

当前续跑实现会重新读取缓存中的失败项并再次报错，**不要直接原样使用旧 `--resume` 命令**。补测需要保留失败证据、单独处理失败项；已完成的 644 次无需因检查器启动失败而全部重跑。
