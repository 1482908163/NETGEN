## 与已有方法的区别

旧版逐四面体排序活跃点、输出链边列表，再复制为 CSR（压缩行存储），保留跨单元重复边。本版 `node_rules_recovery_dag_compact`（紧凑依赖队列）：

1. 复用 `PointFunction`（点函数）已建立的点—单元邻接表。对每个活跃源点，在每个关联四面体中找颜色最小且严格高于源点的活跃点，得到旧链的直接后继。
2. 使用点数大小的标记数组按源点去重；直接连续追加各行后继。队列接管行偏移和后继数组，避免临时边对列表与第二次图复制。
3. 去重后入度与完成释放同步减少；仍使用旧队列的锁、等待、异常唤醒与原线程组。没有新增线程、派发阈值、局部数学或点内求和顺序变动。

纯四面体、无单域筛选条件下，已有邻接表覆盖这些点的关联单元。对每个单元按颜色排序的链，其后继正是上述最小高颜色点；去除重复边不改变先后约束。混合单元、单线程或非静默诊断继续回退原颜色实现并记录覆盖。
不复用跨平滑轮的图：恢复可能改变拓扑；本轮没有未经验证的跨轮缓存。

这是降低前版图构建成本的工程改进，区别于历史同色点分块、恢复拓扑重建去重和旋转链融合。邻接间接访问可能抵消节省；不能仅凭边数下降判定有效。

## 核验与计时

模式 0 关闭；1／2 是旧图正式／重放；3／4 是紧凑图正式／重放。

- 紧凑图预热先用旧逐四面体构造器独立生成参考边，核对原始边数及精确的去重后边集合；再按原颜色执行并核对全部点坐标位模式、类型、层号和奇异因子。任一不同立即失败。
- 正式模式只执行候选，图核验和点参考重放均关闭。参考核验成本单列于参考秒数，不混入建图秒数；完整核心计时仍包含候选所有准备、释放、同步和数据访问成本。
- 增加原始边、去除重复边、图核验调用数。要求原始边减去重复边等于实际边，预热图核验次数等于依赖调用数，正式为零；同时保留点数、完成数、提前跨色、回退和不一致记录。
- 原 15 项统计接口仍只写 15 项；新增三项通过独立接口读取。旧批次没有新字段仍可分析，不补造历史去重数据。
- 原队列检查扩展为 14 项：旧九项，加紧凑图 1／2／4 线程的顺序与数值对照、越界行偏移拒绝、缺边识别。每个候选质量预热先执行预编译检查程序；检查失败或版本不符停止该候选。检查不在助手本地执行。
