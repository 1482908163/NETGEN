## 问题与改动

原规则入口因 `tol > 5`（容错等级超过 5）而串行回退，以保留原诊断文字次序。
当前默认诊断流没有缓冲区。新增可选的 `quiet_rules`（无输出规则并行）仅在以下条件同时满足时
对这部分调用使用已有规则队列：本地模式 1/2、无缓冲区、无流异常掩码、无绑定流、
`testmode` 关闭且没有规则显式测试标志。默认关闭，不扩展远程、自适应或子树路径。

工作线程使用私有无缓冲区流，绝不并发写共享流。局部诊断标志、问题字符串、最小值分类、
几何验证、自由区变换历史、候选比较和同分决策均保留。
无输出期间也保留原串行调用编号；重放模式由串行重放推进一次，避免恢复输出后编号改变。前沿和旋转顺序不变。
有输出缓冲区的流即使处于错误状态也继续回退；不能用“当前没有输出”推断诊断可以删除。

`GenerateMesh`（网格生成）会按上一轮状态设置全局 `testmode`，因此仍有部分无输出调用回退。
旧 `debug_fallbacks`（调试回退）计数混合不同原因，不能当作精确的高容错数量。
旧 `wall-copy-dispatch`（总调用减复制和派发区间）混有归并、队列、构建/销毁等成本，
不能全部归因于串行；派发区间自身还包含工作线程执行。

本版复用原有调用时钟，新增独立八项统计接口，不扩旧数组：高容错调用数/秒数、
符合静默条件的调用数、实际并行数/秒数、重放数、不一致数、串行数。
逐进程检查 `high_calls = parallel_calls + serial_calls`、重放覆盖、时间包含关系及有限非负值。
无覆盖运行保留并标为未覆盖，不当成优化成功。新量进入全进程精简记录与关键进程报告；
旧缓存缺项保持未知，不能补成零。

这是已有规则并行的覆盖修正，尚不是新的跨节点负载均衡算法或已成立的论文创新。

## 正确性与验证边界

- 新增 18 组高容错 1～45 对照：三种输入、1/2/4 线程、正式/重放，与修改前规则源码指纹比较。
- 8 组诊断回退配对：正常捕获、带缓冲区的坏流、绑定流、全局测试标记；结果及输出字节指纹相同。
- 2 组流切换配对：在无缓冲区的高容错区间之后恢复低容错显式诊断，核对全部输出字节及调用编号。
- 9 次真实前沿重试/退出检查：三个过严质量样例，原串行、正式、重放；合计覆盖 3,186 次高容错并行。
  这些样例按原条件到达容错 50，返回原 `MESHING3_NEGVOL`（原负体积返回码），未生成网格。
  核对返回码、输出状态、迭代及搜索工作，并与修改前源码比较；不能称九次成功网格生成。
- 原有规则、共享准备、前沿闭包、包含判断、成功完整生成、拓扑准备、恢复及真实 MPI（消息传递接口）回归继续执行。
- 48 项分析/编排测试，候选 API（程序接口）参数/缓冲区长度检查，统一运行器精简与恢复流程。
