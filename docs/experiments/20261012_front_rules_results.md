# 完整规则成本实验分析：有效规模、真实长尾与下一步选择

## 结论

本轮补齐了完整规则成本证据，**没有新增算法加速结论**。128、256 进程的三路线正确性与配对证据通过独立核查；512 进程未完成有效配对，整批不能判为全部通过。

原计算最慢进程上的规则成本明显随分区变化：128 进程约占计算段 4.43%～13.18%，256 进程约占 17.51%～39.82%。自由区变换和面扫描是稳定的大项，候选评价仅约占规则时间 1.65%～2.13%。因此不继续优化小成本的质量评价，也不因变换占比大就重新开启已有负结果的变换复用。

下一项 B 路线优先审查**面扫描的重复编号转换与数据遍历组织**，以减少真实重复工作为目标，保留几何判据、浮点顺序、候选顺序和规则历史状态。A 路线仍需面对进程间真实工作量集中；C 路线和集群 PMIx 启动故障须分开判断。本次没有修改 A/C 算法。

本次读取并逐字节核对 194 个上传文件的 Git 对象指纹，恢复 CSV 原始 CRLF 换行后核查原始大小与指纹。核查依据与所有输入的路径、大小、Git 指纹及 SHA256 保存在同目录 `20261012_front_rules_audit.json`。

总计/细分正式运行共 **3,456 个同进程配对**，17 项规则工作计数逐进程一致。调用数、规则数、完整映射数与独立距离计数一致；十一桶之和与完整总计守恒，小证书的全部规则字段与完整证书一致。原有三路线共同数值工作字段也逐进程核对，避免相同全局总数掩盖工作迁移。

18 个固定进程配对均重新核对原控制的 `critical_rank_breakdown.csv`（关键进程分解），确认选取该次计算第一慢进程；另外两路线从全部进程证书读取同一编号。全部细分秒数、规则占比、控制计算段占比重新计算，与上传表一致；质量及证书源清单的 SHA256 也一致。

## 512 进程失败的解释

上传日志观察到 `MPI_Init_thread` 和 `MPI_Finalize` 的 `PMIx_Fence returned -24`、PMIx 环形集合超时、后续 `Requested nodes are busy`，以及总计路线 `Unable to create step ... Duplicate job id`。失败发生在关闭新增规则诊断的控制路线，不能归咎于新增细分计时。

失败符号报告的二进制/库指纹匹配，但没有可定位到网格源码的崩溃栈。137 本身不是内存耗尽证明，上传调度快照标明作业仍在运行时采集，也不是最终状态。当前证据更支持启动/结束或作业步生命周期问题；具体根因尚未证明。

先读取该作业最终状态，再决定补齐 512 证据。无需为了重做诊断而废弃有效的 128/256 结果，也不应未经核查更换 MPI/PMIx 实现或修改网格算法：

```bash
sacct -j 6086315 --format=JobID,State,ExitCode,NodeList,Reason,MaxRSS,ReqMem -P
scontrol show job 6086315
```

这些仅查询状态；若作业已离开调度队列，`scontrol` 可能查不到，仍保留 `sacct` 输出。下一轮候选实验保留三个规模同批提交和完整质量门槛，512 若再次失败则独立报告。

## 下一步研究决策与停止条件

1. **B：优先面扫描结构。**源码中每个完整候选、每个相交包围盒的面、每个顶点都线性遍历旧规则点寻找编号。先评估把候选点映射直接转为反向关系的完整构建、更新、清理成本，确认能减少足够实际工作；保留面顺序、重复映射的原有覆盖语义和全部几何调用。这个方向尚未实现，不声称能省掉整个面扫描桶。若完整成本不占优势，停止而非继续阈值扫描或跨调用缓存。
2. **B：不重新开启已关闭路线。**自由区变换虽是大项，但它保留退化情况下的历史系数。既有复用收益弱、固定投影大多变慢；不能直接跳过边约束已失败候选的变换。任何减少完整调用的方案须先证明历史状态和诊断输出依赖，并通过完整重放，不以较高拒绝率代替证明。
3. **A：以真实长尾工作组织为依据。**本轮只证明规则工作集中，没有新增调度收益。未来应区分前沿主导与优化/细化主导的关键进程，评估可迁移任务的所有权、状态和粒度；不把另一种子最快的配置推广为通用方案。
4. **C：保持现有通信证据边界。**PMIx 初始化/结束失败独立处理；本轮没有新通信加速证据，不以启动故障驱动通信阈值或融合方式改动。
5. 下一项算法候选以无新增诊断基础为正式对照；质量预热执行完整规则输出/状态重放。正式运行关闭本轮高频细分观察，比较完整核心时间、固定原关键进程、相关阶段和真实工作量，完整计入新增准备与清理成本。不能用本轮约 15%～20% 的观察开销制造候选收益。

本次提交仅保存分析和审计证据，不改变算法、默认参数或统一实验入口。后续候选完成实现和检查后再给一次运行指令。
