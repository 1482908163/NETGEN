本轮实现一个有明确边界的算法实验：消除规则回溯中相同“规则点—局部点”的重复距离计算。这里尚无真实集群的加速结论。

## 原理与正确性边界

`ruler3.cpp` 的面匹配及孤立点匹配，都调用原表达式 `Dist2(local, reference) * PointDistFactor(reference)`。同一次 `ApplyRules` 内原始局部点坐标不变；同一规则的参考坐标和距离因子不变，距离阈值在当前实现中也固定。回溯反复访问相同点对时，可以复用第一次得到的 **double 值**。

- 缓存键包含规则序号、参考点和局部点。缓存生命周期仅限一次 `ApplyRules`，不同规则或新的局部环境不能误用旧值。
- 只缓存距离，不缓存是否接受点、点占用、映射、拓扑约束、自由区判定或规则结果。全部原有遍历顺序、短路判断、回溯、几何检验、浮点比较与串行提交顺序保持一致。
- 最后用于候选误差的 `CalcPointDist` 采用 float 中间运算，**不与这个 double 距离缓存混用**。
- 按需分配缓存行，条目最多 65,536 个，即约 1 MiB 条目内存，另有行容器开销；达到上限后原表达式直接计算。此上限是内存保护，没有新增实验调参轴。
- 不并行整个前沿，也不跳过任何自由区变换。规则的退化平面可能保留旧系数，因此不能把这一可变状态当成纯函数。

## 两条路线和验证

预设 `front_distance` 默认比较 `split_active` 和 `front_distance`。两条路线使用相同的固定点修复、活跃分裂评价、4 个内核线程、全成本记录、全量体网格预热审计、全局编号和邻接路径。只有候选路线启用距离缓存；对照路线同样统计前沿查询和匹配成本。

新 API `Ng_GenerateVolumeMeshFrontDistance` 在原成本/修复/分裂数组之后增加距离模式和 12 项计数，现有公共 API 签名不变。命令行 `--front-distance`：0 原距离计算，1 距离复用，2 距离复用加精确参考回放；模式 2 只允许带全量质量验证的自然计时预热。

预热的每一次 `ApplyRules`：保存调用前状态，运行候选算法，再从相同输入和规则状态运行关闭缓存的参考算法。逐项核对：

1. 返回值和 float 误差位模式；全部局部点坐标的 double 位模式。
2. 面、生成单元、删除面索引及单元类型/区域。
3. 每条规则的成功映射/可用计数、问题字符串、全局辅助最小值。
4. 规则平面系数、变换后自由区顶点和有效包围盒。

回放结束后恢复候选算法状态，包括异常路径；参考路径的计数和计时不混入候选计数。尚未生成自由区顶点的规则包围盒没有初始化，也不会被几何判定读取，因此快照不读取该包围盒。正式运行不分配回放快照、不运行参考算法。

`algorithm_certificate.csv` 保留每个进程的调用、查询、命中、实际计算、回退、规则访问、完整映射、匹配秒数、已验证调用、失配、参考秒数和分配条目数。分析要求：

- 查询 = 命中 + 实际计算；回退不超过实际计算；条目数不超过逐调用内存上限。
- 预热验证调用 = 全部调用，失配为零；正式运行验证/参考指标为零。
- 两路线每个进程的调用、查询、规则访问和完整映射次数相同，不能用全局抵消掩盖逐进程改变。
- 证书身份、源版本、二进制及逐进程工作签名与原始记录一致。
- 全量质量记录除 scheduler 标识外逐项相同；正式运行每轮有实际缓存命中，否则不能认定优化路线被覆盖。

旧二进制在进入 MPI 前被能力标识检查拒绝。失败仍自动保留压缩原始记录、故障定位输出，并继续剩余实验；失败运行不生成 `SUCCESS` 或有效算法证书。

## 分析和停止条件

先检查质量/证书与逐进程工作守恒，再计算同规模、同种子、同轮配对的核心耗时降幅；不把两组独立中位数之比当成主要收益。分别跟踪原长尾进程和候选新长尾进程，核对 `front_distance_apply_seconds`、`kernel_front_seconds`、生成/优化/通信阶段。全部成本包括缓存建立、查找和释放；参考回放仅属于预热。前沿计时位于整个匹配调用范围，不能解释为距离算术的独占耗时。

成功标准是实际计算明显减少，同时前沿耗时和核心配对耗时具有跨种子、跨规模的可重复改善。只有命中或计算次数减少，不能宣称解决负载不均衡。若命中不足，或者查找/分配抵消了收益，就结束这一方向；**不继续试缓存大小、缓存形状和花式分组参数**。随后根据前沿成本占比，转向规则搜索流程或独立几何工作所需的依赖重构。

A/B/C 原主线仍保留：A 继续关注真实关键进程上的计算负载；B 仅在有可分配工作时研究协作资源，不给串行前沿无效加线程；C 保留现有全局编号与邻接验证和完整通信计时，不能相减不同进程的最大值解释通信或重叠收益。本轮代码集中处理 A 的新瓶颈；不声称 B/C 获得新增加速。
