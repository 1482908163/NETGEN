# 从分裂复用转向前沿拓扑枚举

## 已完成实验的结论

结果提交：`8a5539941158dc171531acaf0c0d0e06b7489de3`；代码：`49f847f6460bfbb2fab4ed019e60d77e9313f686`。
实验目录：`mesh_algorithms_20261002-225219`。

432 次正式运行有效，三个规模均无分析异常，27 份自然预热质量审计通过。同规模、同分区三路线的逐进程质量记录完全相同；每个规模有三个实际不同的表面归属指纹。源码、应用二进制和内核身份一致。

分裂候选复用机制已充分执行：144 次候选正式运行的 `reused == applied`，合计 493,920 次成功分裂复用。候选自然预热通过 `verified == applied`、`mismatches == 0` 的原路径精确重算门槛。上传的预热质量摘要没有暴露原始逐进程验证计数，因此不补写未保存的计数。

结论：正确性通过，局部重算确实消除，整体收益没有稳定证据。停止分裂复用的继续调参，保留显式路线。本轮不默认启用该复用，也不叠加上一轮收益同样不稳定的平滑分组。

## 新改动：按已映射顶点索引面与旋转

`Meshing3::ApplyRules` 用回溯匹配规则旧面。原路径逐本地面、逐旋转枚举，然后检查已映射参考顶点是否对应。这些顶点一旦固定，绝大多数面/旋转已经不可能匹配，仍被逐项访问。

新路径建立不可变原前沿的顶点关联索引（incidence index）：每个顶点记录它出现的本地面、面内位置和面顶点数。若参考面的第 `j` 个顶点已映射到本地点 `p`，只有含 `p` 的同类型面才有可能；`p` 在面内的位置 `k` 唯一确定旋转 `r=(k-j) mod n`，用 `1..n` 表示。重复顶点可能给出多个旋转，均保留。

索引返回严格位于当前游标之后、按 `(面编号, 旋转)` 字典序最小的候选。这样保留原有有效候选顺序，不改变规则选择、改善量、质量阈值或几何运算顺序。其他已映射顶点、面占用、拓扑距离、点占用、几何距离、自由区及新单元质量检查仍走原代码。下一张面没有已映射顶点时，直接使用原枚举。

索引只在本次 `ApplyRules` 首次遇到有映射顶点的下一张面时构建，成功的单面规则无需建索引。作用域仅本次调用的原始 `lfaces[0:lfacesplit]`；规则试算追加的临时点和面随后恢复原长度，不改变这些原始面。前沿正式提交后下一次调用重建索引。回溯重新进入时根据当前映射重新选择关联顶点，不缓存过期映射。

这是拓扑上确定不可能的枚举消除，不依赖空间盒尺寸和筛选阈值。之前空间 BVH 筛选的负结果不能证明这项更直接的面旋转枚举改动有效；仍要测量建索引成本和净收益。规则对象存在可变自由区变换，本轮也未引入规则并发。

A 路线保留原域和归属；B 路线继续缩减域内关键计算工作量；C 路线沿用已经验证的 `owner_local_v2` 异步编号和邻接流程。本轮代码新增集中在 B 的原生前沿匹配，不声称 A/C 同时有新性能收益。

## 路线、诊断和正确性门槛

| 路线 | 前沿枚举 | 诊断 |
|---|---|---|
| `batch_parallel` | 原枚举 | 已有基线诊断 |
| `front_profile` | 原枚举 | 增加前沿匹配和原生操作诊断 |
| `front_topology` | 顶点关联索引；无关联顶点时原枚举 | 同上 |

三条路线采用同一整段恢复并行、单线程确定性批量细化及异步编号。三个比较分别识别诊断开销、索引自身收益和相对基线的净收益。

候选自然预热对每次索引查询独立穷举原始面/旋转，精确比较下一项；包含空结果和回溯游标。任何不一致抛出异常，运行失败。分析器要求 `verified == queries`、`mismatches == 0`。正式计时及分阶段预热关闭额外穷举，验证计数必须为零。

仍要求最终网格、编号和邻接严格一致，源码/二进制身份相同。诊断控制与候选还要逐进程比较匹配调用数、通过类型/质量筛选的规则数和完成映射数；只比较全局总数不足以发现跨进程的覆盖变化。

`front_match_` 的十二项指标：

| 指标 | 含义 |
|---|---|
| `calls` | `ApplyRules` 调用数 |
| `builds` | 惰性索引构建数 |
| `queries` | 索引下一项查询数，含返回空结果 |
| `linear_visits` | 原枚举实际访问的面/旋转数 |
| `indexed_visits` | 索引返回的非空面/旋转数 |
| `skipped_slots` | 索引游标跳过的虚拟穷举槽位数 |
| `verified` / `mismatches` | 预热精确验证数/差异数 |
| `build_seconds` | 索引构建累计时间 |
| `seconds` | 匹配调用累计时间，包含构建及启用的验证 |
| `mappings` | 到达原 `foundmap` 统计位置的映射数 |
| `admitted_rules` | 通过原面类型与质量筛选的规则数 |

`skipped_slots` 不是原算法实际访问数：原算法对占用/距离/类型不适合的面也会跳过剩余旋转。实际访问对比用控制 `linear_visits` 与候选 `linear_visits + indexed_visits`；查询数包含终止查询，不能混作访问数。
计数跨进程求和，秒数跨进程取最大；同时输出每次真实最慢计算进程对应指标。累计建索引时间已包含在匹配时间内，不能再相加。预热带验证的时间不用于性能结论。

- 分析器拒绝差异计数、漏验查询、非法计数、不可能计时、缺失策略与逐进程映射覆盖变化；零前沿工作可以有效，但不能声称索引已执行。
- 旧分裂/平滑预设配置及现有全路线分析回归通过。本地测试不提供真实性能收益结论。
