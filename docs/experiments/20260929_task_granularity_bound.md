## 撤回单纯整域重分配建议

设 P 个同速执行位置，每处保持相同核数，每个原域是一个不可拆分任务，持续时间为 t_i；所有任务同时可执行，不考虑通信、争用和迁移成本。目前每处一个任务，计算完成时间已为 max(t_i)。

任何重新放置或动态领取都必须执行最长任务，故完成时间不可能小于 max(t_i)。原分配已达到这一条件模型的下界。即使准确知道全部实测成本，单纯换位置也无法改善计算尾部。

这不是关于真实机器所有放置方式的普遍定理。不同核数、不同节点速度、争用、不同释放时刻、多个域/进程或通信局部性变化，都可能改变持续时间或模型。当前结果未证明这些因素可以带来值得实现的收益。因此不再为同速整域重排安排一轮集群实验。

## 保留体生成不可拆分时的乐观界

使用 `refine_serial`（批量单线程）路线，定义：

- T：各进程计算总耗时最大值；
- W/P：各进程计算总耗时的均值；
- G：各进程 `local_volume_mesh`（本地体网格生成）耗时的最大值。

在原域生成持续时间不变、其余计算可任意拆分搬迁、没有调度通信开销的假设下，计算完成时间仍满足 `T_new >= max(G, W/P)`。因此计算时间可降低的比例至多为 `1-max(G,W/P)/T`。完全可分时的 `1-(W/P)/T` 只是更宽松的理想上限，不能直接当作调度收益。

自然计时，每次运行分别计算界后取 8 次中位数：

| 指标 | 128 进程 | 256 进程 |
|---|---:|---:|
| 当前计算最大耗时 T | 2.690 秒 | 1.966 秒 |
| 平均计算耗时 W/P | 1.759 秒 | 0.932 秒 |
| 最长本地体生成 G | 2.273 秒 | 1.734 秒 |
| 整个计算任务只换位置，条件模型收益 | 0% | 0% |
| 体生成不可拆分、其余理想均衡，计算降幅上限 | 15.28% | 11.78% |
| 所有计算均可理想拆分，计算降幅上限 | 34.61% | 52.41% |

拆分计时对应第二个降幅上限为 15.34%/11.81%，判断相同。表中的阶段中位数之比不必等于逐次比例的中位数。

这些界只针对上述固定耗时计算模型，不能换算为实测核心总时间、MPI 等待或端到端加速保证。
