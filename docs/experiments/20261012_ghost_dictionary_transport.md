# C 路线：真实幽灵顶点字典传输

基于 `1a4430cff6aa852e2d8f79c6507759050835d6d0`。上一批审计在 128/256 进程上确认约 58% 的逻辑载荷削减空间，工作空间仅有局部收益。本轮把字典用于真实 MPI（消息传递接口）传输，并加入启动检查；尚无集群性能结论。

## 实现原理

新增 `--ghost-dictionary`：0 保留原结构体消息，1 按邻居选择字典或原结构体，2 执行同样的真实传输并与原结构体参考通信核对全部接收字段。默认 −1，不启用该研究功能。

原邻居单元数量交换继续使用原流程。字典路线随后为每个非空邻居发送三个 64 位整数，合计 24 字节：格式、原单元数、实际有效载荷字节数。字典载荷仍为 `16 + 32U + 28E` 字节，原载荷为 `140E` 字节。字典不划算、格式容量不足或编码临时分配失败时旁路，发送原 MPI 结构体，不更改几何数据。

每个邻居以编号及三个坐标的完整位模式建立字典。单元编号、域编号、四个顶点编号和坐标位模式完整保留；同编号不同坐标不会合并。单元顺序与原消息一致，接收后仍按原邻居和单元顺序插入网格。

格式元数据、主载荷、预热参考消息使用独立标签。字典字节消息和原结构体消息均按单次 MPI 计数限制分片，逐消息检查实际接收计数；字典再检查精确长度、版本、数量和索引。准备全部缓冲及请求计划后才投递通信，防止分配异常释放仍被 MPI 请求引用的缓冲。等待完成后解码和释放。错误传播到原 MPI 终止路径，避免某个进程失败后其他进程无限等待。

本轮限制在原生成域、原批量幽灵交换和所有者局部 64 位编号上，关闭幽灵流水线、逐邻居提前接收、整域任务调度及独立字典审计。两条路线均使用原临时工作空间，保持固定修复、活跃分裂和有序邻接一致。属于通信表示改造，不能称为新增进程负载均衡算法。

## 正确性与完整成本

预热的候选路线在真实接收后，再用原 MPI 结构体发送一次相同消息。逐邻居比较全部接收单元的单元编号、域编号、顶点编号及坐标字节，检查完整覆盖和零差异；参考通信仅出现在预热。

保留原完整质量检查、修复/分裂/邻接参考核对。两路线全量质量文件、逐进程工作量及原幽灵单元计数必须一致；正式运行不执行参考通信。未知格式、错误长度、短消息、证书篡改、缺进程、请求路线未执行和质量漂移均拒绝成功报告。

`ghost_transport_full_seconds` 测量同一进程从幽灵交换函数开始到结束的整段成本：原打包、原数量交换、准备、格式/长度交换、主传输、解码、网格插入、MPI 数据类型释放以及发送/接收载荷和描述数组最终释放。预热参考时间单独记录，正式参考时间为零。

另有准备、元数据、主传输、解码、释放及传输子段总时间，只读阶段边界时钟，不在每个单元中计时。按实际发送的有效字节和分片消息数更新通信统计。`retained_wire_bytes_peak` 是保留的序列化发送/接收缓冲容量峰值，不包含字典构造临时表、原单元缓冲或全进程内存，不能当作驻留内存峰值。

报告固定原路线整段交换最慢的进程，再对照候选的同编号进程；核心时间使用原完整核心口径，剔除粗网格阶段。不相加不同进程的阶段最大值，也不从自然等待时间推算纯网络耗时。

## 快速启动检查

新增 `--mpi-preflight`，完成 MPI 线程初始化、全进程归约结果核对、屏障和结束，不进入网格初始化。统一入口在同一节点数、进程数、预留核数及启动器下执行一次，默认限时 60 秒。

每个作业分配和二进制身份只检查一次。失败立即停止当前分配的网格实验，其他规模作业继续；保留 `mpi_startup/receipt.json`、`mpi_startup/log_tail.txt` 和 `ALLOCATION_STOPPED.json`。完整日志在本地 `mpi_startup/run.log`。这用于减少初始化失败的重复等待，不代表修复 PMIx（进程管理接口）环境，也不能保证后续启动不会再出故障。
